# Scrolling, Zooming & Rotating

## Scrolling (for example via Keyboard Shortcut)[​


You can use the predefined actions "Start Smooth Scrolling" and "Stop Smooth Scrolling". For example you can assign them to a keyboard key/shortcut on key down and key release.
