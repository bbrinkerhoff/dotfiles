# Getting Started


- Add the predefined action **[h@llo.ai - Show Customizable AI Assistant** to any BetterTouchTool trigger.

- Choose an AI backend in the assistant configuration and add the required API key, login, local server URL, or CLI setup.

- Open **AI Configuration -> Tools & Context -> Manage Skills...**.

- Enable the skills that match the assistant's job.

- Trigger the assistant and start with a small request.


## Good First Setup[​


For a general BTT helper, enable:


- **General Assistant**

- **BTT Expert**


Then ask something simple, for example:

```
`Create a keyboard shortcut that shows a HUD saying "Hello".
`
```


Once that works, add more focused skills such as **Computer Use**, **Background Computer Use**, **Research Assistant**, or **Floating Menu & Widget Creator**.


## Keep It Focused[​
