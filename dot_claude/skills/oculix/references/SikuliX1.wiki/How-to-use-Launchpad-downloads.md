### SikuliX IDE
[Be sure you know the prerequisites](http://www.sikulix.com/quickstart/).

Put the downloaded artefact `sikulix-2.0.x.jar` in a folder of your choice.

To edit and run scripts, you might need additional stuff:

* to use Python as scripting language [download Jython](https://repo1.maven.org/maven2/org/python/jython-standalone/2.7.1/jython-standalone-2.7.1.jar)
* to use Ruby as scripting language [download JRuby](https://repo1.maven.org/maven2/org/jruby/jruby-complete/9.2.0.0/jruby-complete-9.2.0.0.jar)

Put the artefacts in the same folder as the `sikulix-2.0.x.jar` and start the IDE:

* by double-clicking on `sikulix-2.0.x.jar` or
* by running in a commandline `java -jar path-to-sikulix-2.0.x.jar`

[For more information about features and usage read the docs](https://sikulix-2014.readthedocs.io/en/latest/index.html)
